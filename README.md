# Breast Cancer Prediction using Random Forest

## 📌 Objective
This project focuses on applying the Random Forest algorithm to predict whether a tumor is malignant or benign.
Model built using Random Forest Classifier with feature importance analysis.

## 📊 Dataset
- Breast Cancer Dataset (UCI / Kaggle)
- Type: Classification

## 🚀 Project Workflow
- Data loading and exploration
- Data preprocessing
- Train-test split
- Random Forest model training
- Model evaluation (Accuracy, Precision, Recall, F1-score)
- Hyperparameter tuning
- Feature importance visualization

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## ▶️ How to Run
1. Open the `.ipynb` file
2. Run all cells step by step

## 📈 Results
- Model predicts breast cancer diagnosis effectively
- Achieved good accuracy
